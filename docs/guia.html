Guía de instalación

Ponerlo en marcha en tu equipo

Media hora la primera vez, y casi toda se va en registrar las cuentas. Ni terminal ni saber programar: se descarga, se abre con doble clic y las claves se pegan en un formulario.

Requisitos Claves Instalación Primera pasada Coste Si algo falla

Requisitos

  • Imprescindible

    Spotify Premium

    Desde marzo de 2026, quien registra la aplicación debe tener suscripción de pago. Con una cuenta gratuita, Spotify deniega la creación de listas.

  • Imprescindible

    Un modelo de lenguaje

    Es lo que perfila tu catálogo. Con Claude u OpenAI necesitas clave de API y saldo; con Ollama o LM Studio el modelo corre en tu equipo, sin clave y sin coste.

    Claude OpenAI Ollama LM Studio
  • Recomendable

    Cuenta de Last.fm

    Gratuita. Aporta el vocabulario que la comunidad ha escrito sobre artistas y discos, y es lo que sostiene el perfilado del catálogo menos conocido.

Las claves

  1. Spotify

    En developer.spotify.com/dashboard, pulsa Create app. Marca Web API y pega este Redirect URI, comprobando que queda añadido a la lista:

    </>Redirect URI
    http://127.0.0.1:8000/api/auth/callback

    Guarda, entra en Settings y copia el Client ID. El secreto no hace falta. Añade también tu cuenta en User Management.

  2. El modelo

    Con Claude: en console.anthropic.com, crea una clave en API keys y compra crédito en Plans & Billing. Con Ollama o LM Studio no hay clave que copiar: basta con instalarlos, descargar un modelo y dejarlos abiertos.

  3. Last.fm

    En last.fm/api/account/create, rellena nombre y descripción y deja el resto en blanco. Sólo necesitas la clave, no el secreto.

Instalación

  1. Descargar

    Desde GitHub: Code → Download ZIP, y descomprime donde quieras.

  2. Doble clic

    Compás.command en macOS, Compas.bat en Windows. La primera vez instala lo que falte y tarda un par de minutos; después arranca en segundos y abre el navegador solo.

  3. Pegar las claves

    Compás arranca aunque no esté configurado y te lleva a ajustes, donde pegas las claves en un formulario. Se guardan en tu equipo y la aplicación se reinicia sola.

Prefiero hacerlo por terminal
</>bash
git clone https://github.com/pclavellmaso/spotify-playlist-gen
cd spotify-playlist-gen
uv venv --python 3.13 .venv
uv pip install --python .venv/bin/python -r requirements.txt
cp .env.example .env
./.venv/bin/python run.py

Vale cualquier Python 3.10 o superior. En macOS 26 conviene uv, porque la compilación de Homebrew no permite crear entornos virtuales.

La primera pasada

El orden importa: el segundo paso es el único que cuesta dinero.

01

Sincronizar

Baja tu catálogo. Gratis y repetible.

02

Perfilar cincuenta

Prueba con pocas y pide un par de momentos. Si el resultado no convence, mejor saberlo antes del catálogo entero.

03

Barrido

Sube el tope y déjalo correr. Puedes cerrar la pestaña: se guarda lote a lote.

Coste

Lo pones tú, y va según la tarifa de la API que elijas. El gasto se concentra en el perfilado inicial y no se repite: cada canción se analiza una sola vez y el resultado queda guardado. Con un modelo local no cuesta nada, y Spotify y Last.fm no cobran.

Si algo falla

No puedo iniciar sesión: INVALID_CLIENT

El Redirect URI del panel de Spotify no coincide exactamente con http://127.0.0.1:8000/api/auth/callback.

Revisa que no ponga localhost, que no sobre una barra final y que esté añadido a la lista, no sólo escrito en el campo.

La barra de análisis se queda a cero

Casi siempre es falta de saldo en la cuenta del modelo. El aviso aparece en rojo dentro del panel de biblioteca.

Con Ollama o LM Studio, comprueba que el programa esté abierto y con un modelo descargado.

No puedo guardar la playlist

Tu cuenta tiene que estar añadida en User Management del panel de Spotify y ser Premium.

Si cumples ambas cosas, actualiza el proyecto: Spotify cambió varias rutas en febrero de 2026 y las versiones antiguas fallan con un error que parece de permisos.

Mis playlists aparecen con cero canciones

Mismo origen que el anterior. Actualiza el proyecto.

macOS no me deja abrir el lanzador

La primera vez el sistema bloquea los ficheros descargados de internet. Clic derecho sobre Compás.command → Abrir → Abrir. A partir de ahí, doble clic normal.

Casi ninguna canción supera la nota

No es un fallo: tu biblioteca no tiene música para ese momento. Baja la exigencia o pulsa ampliar la búsqueda, que relaja el listón por pasos y te enseña la nota de cada tema para que veas lo que cedes.
