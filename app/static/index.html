    Cómo funciona

    Tres pasos, y el segundo solo se paga una vez

    01

    Sincroniza

    Se baja tu biblioteca de Spotify a una base SQLite local: título, artista, álbum y año. Nada más, y nada sale de tu ordenador.

    02

    Analiza

    Claude perfila cada canción en siete ejes —energía, luminosidad, cuánto invita a bailar…— apoyándose en los tags de comunidad de Last.fm. El resultado se guarda: cada canción se analiza una sola vez.

    03

    Describe

    Escribes el momento en lenguaje normal. Se traduce al mismo espacio de siete ejes y se compara con aritmética, sin IA: barato, determinista y con tests.

    Qué necesitas

    Tres cuentas, dos de ellas gratis

    • Obligatorio

      Spotify Premium

      Desde marzo de 2026, quien registra la aplicación tiene que ser Premium. Sin eso, Spotify deniega la creación de playlists.

    • Obligatorio

      Una IA con API

      Por defecto Claude, con saldo en la consola de Anthropic. Es lo que perfila tu música. El modelo se cambia con una variable de entorno, así que mañana puede ser otro.

    • Opcional

      Last.fm

      Clave gratuita. Aporta los tags de la comunidad, que es lo que salva el catálogo que el modelo no conoce. Sin ella funciona igual, solo que peor con música de sello pequeño.

    Montarlo en local

    Cuatro pasos desde cero

    1. Clona e instala

      git clone https://github.com/pclavellmaso/spotify-playlist-gen
cd spotify-playlist-gen
uv venv --python 3.13 .venv
uv pip install --python .venv/bin/python -r requirements.txt

      Sirve cualquier Python 3.10 o superior. Se usa uv porque en macOS 26 el Python de Homebrew viene roto.

    2. Registra la aplicación en Spotify

      En developer.spotify.com/dashboard, crea una app, marca Web API y añade como Redirect URI exactamente esto: 

      http://127.0.0.1:8000/api/auth/callback

      Tiene que ser 127.0.0.1. Spotify ya no acepta localhost, y si no coincide carácter por carácter el login falla. Añade también tu cuenta en User Management.

    3. Pon las claves

      cp .env.example .env

      Dentro van el Client ID de la app de Spotify (el secret no hace falta, se usa PKCE), tu clave de Anthropic y, si quieres, la de Last.fm.

    4. Arranca

      ./.venv/bin/python run.py

      Se abre en http://127.0.0.1:8000. Inicia sesión, sincroniza, analiza unas cincuenta canciones para ver qué tal salen los perfiles, y a partir de ahí describe momentos.

    Conviene saberlo

    Esto no puede ser un producto público hoy

    Spotify limita las aplicaciones nuevas a cinco usuarios de prueba. Salir de ahí exige empresa registrada y 250.000 usuarios activos al mes. Como herramienta personal —tú y cuatro personas más— funciona perfectamente; como producto abierto, no es viable. Por eso vive en tu máquina.

    Además, Spotify retiró en 2024 los datos acústicos que hacían fácil esto. El perfil de cada canción es una estimación del modelo, no una medición, y por eso lleva un nivel de confianza: cuando no reconoce un tema, su perfil pesa menos en vez de decidir por su cuenta.
