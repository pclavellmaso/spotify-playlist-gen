Guía de instalación

Ponerlo en marcha en tu equipo

Media hora larga la primera vez, contando el registro de las cuentas. No hace falta saber programar, pero sí abrir una terminal y pegar cuatro órdenes. Cada paso incluye lo que puede salir mal.

Antes de empezar

Compás no es un servicio al que te registras: es un programa que corre en tu ordenador y habla con tres servicios en tu nombre. Eso significa que las cuentas y el gasto son tuyos, y que ninguna canción ni credencial pasa por un servidor mío. También significa que hay que montarlo.

  • Imprescindible

    Spotify Premium

    Desde marzo de 2026, quien registra la aplicación debe tener suscripción de pago. Con una cuenta gratuita todo parece funcionar hasta que intentas guardar una lista y la API responde un error genérico de permisos.

  • Imprescindible

    Saldo en un modelo de IA

    Por defecto Claude, con créditos comprados en la consola de Anthropic. No sirve la suscripción de la aplicación de chat: es otra cosa. Hace falta una clave de API y saldo, que se compra por adelantado.

  • Recomendable

    Cuenta de Last.fm

    Gratuita y sin límite práctico. Aporta el vocabulario que la comunidad ha escrito sobre artistas y discos, y es lo que sostiene el perfilado del catálogo menos conocido. Sin ella funciona, con peor puntería.

Cuentas y claves

  1. Registrar la aplicación en Spotify

    Entra en developer.spotify.com/dashboard con tu cuenta de siempre y pulsa Create app. Nombre y descripción, lo que quieras.

    En Redirect URI pega exactamente esto y pulsa Add, comprobando que aparece en la lista de abajo y no sólo escrito en el campo: 

    http://127.0.0.1:8000/api/auth/callback

    Ha de ser la IP de bucle. localhost dejó de aceptarse y una sola letra de diferencia tumba el inicio de sesión.

    Marca Web API y nada más. Guarda, entra en Settings y copia el Client ID: son 32 caracteres hexadecimales. El client secret no hace falta, porque se usa PKCE.

    Por último, en User Management, añade tu propia cuenta con su nombre y el correo con el que entras en Spotify.

    Cuidado con una confusión fácil: en el panel hay una sección aparte llamada Spotify Soloist API Key, que es un reproductor para terminal y no tiene nada que ver. Lo que buscas se llama Client ID y no se genera con un botón: ya lo tiene la aplicación que acabas de crear.

  2. Obtener la clave del modelo

    En console.anthropic.com, apartado API keys, pulsa Create key. Cópiala en ese momento: empieza por sk-ant- y no se vuelve a mostrar.

    Entra después en Plans & Billing y compra crédito. Sin saldo, cada petición devuelve un error y no se perfila nada.

  3. Obtener la clave de Last.fm

    En last.fm/api/account/create, rellena nombre y descripción. Los campos de callback y página web pueden ir vacíos: no se usa autenticación de usuario. Te da una clave y un secreto; sólo hace falta la clave.

Instalación

  1. Descargar el proyecto y crear el entorno

    git clone https://github.com/pclavellmaso/spotify-playlist-gen
cd spotify-playlist-gen
uv venv --python 3.13 .venv
uv pip install --python .venv/bin/python -r requirements.txt

    Vale cualquier Python 3.10 o superior, y sirve python -m venv si el tuyo está sano. En macOS 26 conviene uv (brew install uv): la compilación de Homebrew de Python viene con una biblioteca del sistema desemparejada y no deja crear entornos virtuales.

  2. Escribir las credenciales

    cp .env.example .env

    Abre el fichero y rellena estas tres líneas, sin comillas ni espacios:

    SPOTIFY_CLIENT_ID=el_client_id_de_32_caracteres
ANTHROPIC_API_KEY=sk-ant-...
LASTFM_API_KEY=la_clave_de_lastfm

    .env está excluido del control de versiones y debe seguir estándolo. Lo mismo que la carpeta data/, donde viven la base de datos y tu token de sesión.

  3. Arrancar

    ./.venv/bin/python run.py

    Queda servido en http://127.0.0.1:8000. Ábrelo en el navegador y entra con Spotify: se abrirá la pantalla de autorización pidiendo permiso para leer tu biblioteca y crear listas.

La primera pasada

El orden importa, porque el segundo paso es el único que cuesta dinero y conviene comprobarlo sobre una muestra antes de lanzarlo entero.

  1. Sincronizar

    Baja tu catálogo a la base local. Es gratis, tarda poco y puede repetirse cuando quieras: sólo añade lo que falte.

  2. Perfilar una muestra

    Deja el tope en cincuenta y pulsa Analizar. Cuando termine, pide un par de momentos y juzga el resultado. Si con tu música los perfiles no tienen sentido, es mejor saberlo aquí que después de pagar el catálogo completo.

  3. Lanzar el barrido

    Sube el tope y déjalo correr. Puedes cerrar la pestaña: el trabajo sigue en el proceso y se guarda lote a lote, así que una interrupción sólo cuesta el lote en vuelo.

Cuánto cuesta

El gasto está concentrado en el perfilado inicial y no se repite: cada canción se analiza una sola vez y el resultado queda guardado. Interpretar una petición es una llamada corta y suelta, de céntimos. Last.fm y Spotify no cobran nada.

Abaratarlo. Con ANTHROPIC_MODEL=claude-haiku-4-5 el barrido inicial baja mucho, a cambio de precisión en el catálogo menos conocido. Es un buen intercambio si tienes miles de canciones.

Repetirlo. Si se toca el vocabulario de ejes o contextos, las etiquetas guardadas dejan de valer y hay que volver a perfilar. Por eso conviene validar sobre una muestra antes del barrido.

Errores frecuentes

Todos estos han pasado de verdad durante el desarrollo. Los mensajes de la API de Spotify son especialmente engañosos: varios cambios de 2026 devuelven un 403 de permisos cuando en realidad la ruta ha cambiado.

INVALID_CLIENT al iniciar sesión
El Redirect URI del panel no coincide carácter por carácter con http://127.0.0.1:8000/api/auth/callback. Revisa que no sea localhost, que no sobre una barra final y que esté efectivamente añadido a la lista.
La barra de análisis se queda en cero y desaparece
Casi siempre es falta de saldo en la consola de Anthropic. Debería aparecer el aviso en rojo bajo la barra; si no, mira la terminal.
Error al guardar la playlist
Comprueba que tu cuenta esté en User Management y sea Premium. Si aun así falla, asegúrate de tener la versión actual del código: hasta febrero de 2026 la ruta para añadir canciones era otra y la antigua ahora responde un 403 que parece de permisos.
Las playlists aparecen con cero canciones
Mismo origen: Spotify renombró el campo del recuento. Actualiza el proyecto.
ensurepip falla al crear el entorno
Es el Python de Homebrew en macOS 26. Instala uv y crea el entorno con él, que trae su propio intérprete autocontenido.
Casi ninguna canción supera la nota
No es un fallo: significa que tu biblioteca no tiene música para ese momento. Baja la exigencia o usa ampliar la búsqueda, que la va relajando por pasos y te enseña la nota de cada tema para que veas lo que estás cediendo.

Hacia dónde va

Otros modelos

El modelo ya se elige con una variable de entorno, pero el cliente es el de Anthropic. Aislar esa parte detrás de una interfaz común dejaría usar cualquier proveedor con API compatible, y ejecutar el perfilado contra un modelo local para quien no quiera pagar nada.

Una versión alojada

Técnicamente es viable: el perfilado ya es asíncrono y el estado cabe en una base pequeña. El obstáculo no es técnico. Spotify limita cada aplicación a cinco usuarios de prueba, y ese límite va asociado a la aplicación, no al lugar donde se ejecuta: alojarla en un servidor no lo levanta. Abrirla a más gente exigiría cuota extendida, que pide empresa registrada y 250.000 usuarios activos al mes.
